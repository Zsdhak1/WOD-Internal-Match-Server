# 正式 BO3 比赛与裁判录入辅助

## 范围

正式模式默认开启，旧 60 秒击杀积分 / SUDDEN DEATH 保留为显式“旧调试”配置。results-web 已弃用，本次不修改其公开页或数据库。裁判在 Qt 服务端复制本局结算信息，填写外部成绩系统；本程序不自动上传。

本次实现不是完整赛事管理平台：不包含小组获胜点总榜、抽签和自动晋级，也不证明实车已经通过规则或安全验收。规则手册未明确的资源全同、同时耗尽和不确定设备状态不会自动进入加时，而是等待人工裁决。

## 操作流程

1. 启动 UDP 监听。等待设备注册，分配唯一机器人 ID 与红/蓝方。正式对局每侧必须恰好一台在线 V2 设备，MAC、ID 和地址唯一且业务状态已确认。
2. 导入 UTF-8 CSV/TSV/TXT 或 JSON 队伍对阵表。导入和下拉预选不立即切换；点击“应用所选对阵”才提交。禁止同名队伍对战自己。
3. 点击“开始本局 · 5秒倒计时”。倒计时中可取消，取消时不会发送 GAME_START。
4. 归零后只向当前 BO3 的两台绑定设备发送 GAME_START。必须双方成功回执和新鲜的存活 300HP 状态都确认后，才启动服务端权威 180 秒时钟。失败显示异常，并发送结束命令，不能宣称实车已安全停机。
5. 正式小局每方分配 3 次复活。设备死亡等待至少 5 秒后发出请求；服务端核对本轮、设备、已观察死亡及额度后批准。比赛中显示剩余次数和“确认中”提示。
6. 一方复活耗尽且血量归零，经过同时击毁确认窗口后提前判负。到时先比剩余复活次数，同次数再比实际 HP。判罚优先。未知、离线、阵亡与 HP 矛盾或复活执行仍未确认时，不把未知当零，等待裁判核实。
7. 小局结算更新 BO3 胜局数，并自动显示“裁判录入辅助”页。可以复制本局文本或 JSON；只允许填写本地可选备注，不改原裁决。
8. 尚未有人赢满两局时进入 120 秒局间准备。归零只解锁开赛按钮，不自动让设备开动。再次由裁判确认，经 5 秒倒计时后开始下一小局，复活额度重置但 BO3 胜局数保留。
9. 2:0 或 2:1 后整场结束，不产生第四小局或多余准备阶段。切换对阵会撤销旧选手登记、清理旧视频归属，要求重新登记；保留已归档的每局结果。

正式模式不新增技术暂停。BO3 内锁定对阵、设备身份和管理员 HP 改写；不要把停止网络监听或重发 GAME_START 当作暂停/继续。安全操作仍须依靠现场实体急停与裁判流程。

## 裁判辅助数据

每小局提供：场次/局标识、双方队名、BO3 小局号及胜局数、胜方、双方剩余 HP 与剩余复活次数、结束方式、明确判定原因和本局用时。结束方式为：常规结束、耗尽复活、违规判负、安全终止、时间判定。

未有效结算时不猜胜方。缺失数据和确认中的额度显示“未提供”，合法 0 仍为 0。复制副本保留未知及警告，不能用默认值冒充遥测。赛后原始快照以独立 JSON 原子归档；测试使用临时 INI 与临时归档目录，不写正式裁判配置。

## ESP32 复活审批

与 `2470519590/ESP32-S3-Module-for-Judgement-System` 的 `2f4abbe` 对接：

```text
请求 0x0D: 54 52 02 0D robot_id request_sequence request_tx[4]
批准 0x89: 54 52 02 89 robot_id request_sequence request_tx[4]
```

均严格为 10B，小端。批准回显请求序号与事务号，不分配新的事务号。普通 F0 ACK 不是批准；批准成功回执为 F0、acked_type=0x89、原 request_tx、result=0。

审批账本按物理设备 MAC + 帧类型 + 请求事务号保存，并关联局标识和已观察死亡周期。先持久化决策/额度占用再发送，重复请求和重复回执不重复扣次数。同一死亡换事务号也不额外发放。回执超时和 result=2 是执行结果未知，保留占用并重试原批准，不释放后再发新额度。ACK 校验来源设备 IP、类型、事务号；同 IP 多设备相同事务的歧义不自动确认。

到时、结算和局间准备停止旧轮批准重试。迟到回执归旧账本，不在新局再扣一次。服务器重启加载全局去重账本，但不自动恢复一场可能已经改变的比赛。

### 必须保留的协议限制

当前 UDP 请求没有比赛 epoch、生成时间或完整死亡 ID，ESP32 NVS 会跨重启保留请求。因此首次收到的未知旧请求不能仅凭接收时刻严格证明属于当前局。开赛 ACK + 新鲜存活状态，以及服务端当前死亡周期校验可以降低风险，但不是严格的跨局证明。严格保证需设备侧补充局标识/清理握手，本次不擅自修改线上帧长。

当前 STATUS 也没有可比较的生成序号/时间戳。代码会将“阵亡却仍是正 HP”的当前矛盾冻结为待裁决，但不能声称抵御所有晚到存活状态。真实 L431 的新复活契约、三次配额、发射/运动安全互锁、断网与重启行为须实车联调。
