## 坐标约定

所有坐标均为原图像素坐标，格式为 `[x1, y1, x2, y2)`：

- 原点位于图片左上角。
- `x1, y1` 是左上角坐标。
- `x2, y2` 是排他坐标，切图时宽度为 `x2 - x1`，高度为 `y2 - y1`。
- JSON 中的 `size` 已给出对应宽高。

标注颜色含义：绿色为可直接使用，黄色为可选或需要改作，红色为当前不使用。参考 UI 中的橙色框表示需要改作。

### Notepad Atlas 建议

- 本项目不需要 `Round-1` 至 `Round-5` 标签，因为比赛固定为 `1v1`、`60 秒`。
- 比分建议使用可缩放文字，避免贴图数字在大屏分辨率下尺寸受限；`N08-N13` 可作为备用风格素材。
- `N14` 可用于中央计时器或赛事标题的顶部装饰边框。
- `N15` 已用于导播台中央比赛计时/比分背景面板。
- 原先统称为 `N16` 的区域实际由上下两个组件组成：`N16A` 和 `N16B`。使用时需要按左右方向放置：`N16B` 放在 `N15` 左侧承载红方小局积分，`N16A` 放在 `N15` 右侧承载蓝方小局积分；两者均绘制在 `N15` 前方并压住边缘。

### Statusbar Atlas 推荐取用组合

1. 红方主血条：优先 `S62`；空间较紧时使用 `S56` 或 `S40`。
2. 蓝方主血条：优先 `S63`；空间较紧时使用 `S57` 或 `S33`。
3. 牌面显示：`S01` 为红牌，`S17` 为黄牌；导播台控制台可以对选中机器人追加牌面并清除显示。
4. 机器人热量：使用 `S09`，与 HP 条分开显示，数值来自状态帧的可选热量扩展字段。
5. 队名覆盖层：使用 `S44` 作为队名底板，也可以组合 `N14` 做顶部边框装饰。
6. 机器人身份图：从 `S42/S43/S45/S47/S49/S52/S60` 中选一张红方图，从 `S31/S38/S39/S46/S48/S51/S59` 中选一张蓝方图。金色选中圈可以改作在线、当前导播焦点或视频源连接状态。
7. 当前不建议使用等级徽章、其他资源条、护盾图标、空槽位、绿色/洋红色状态条，因为项目状态模型只需要红蓝双方的机器人信息、热量和比赛计时。

## 四、导播台页面落地建议

全屏转播窗口以实时视频为底层，UI 只作为透明叠加层：

- 顶部左侧：红方队名，下面放红方机器人 HP 条和状态图。
- 顶部右侧：蓝方队名，下面放蓝方机器人 HP 条和状态图。
- 顶部中央：`红方比分 - 蓝方比分` 与 `60` 秒倒计时。
- 受击时：对应血条闪烁、短时显示 `S01/S12/S17` 告警素材，并在日志或事件层显示伤害来源。
- 机器人视频源切换不会改变 UI 数据绑定，红蓝方身份由登录登记和服务端机器人 ID 绑定决定。
- 控制台窗口负责队名、比分、计时、红蓝方机器人 ID、视频设备选择、手动/自动切换视角，以及受击事件回放或清除。

标注图用于视觉确认，实际程序应优先读取 JSON 中的坐标清单，避免手工复制坐标造成偏差。
